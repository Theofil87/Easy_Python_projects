# BLOKK — Tetris

A playable browser Tetris game with keyboard and touch controls, hold/next pieces, scoring, levels, line clearing, pause, and local high-score persistence.

## Play

Open `index.html` directly in a browser, or serve the `games/tetris` directory with any static web server.

## Controls

- Arrow keys / A-D: move
- Arrow Up / W: rotate
- Arrow Down / S: soft drop
- Space: hard drop
- C: hold piece
- P: pause
